A bespoke luxury fragrance theme for Scentral Attraction, Perfume & More.

== Description ==

Editorial design system ("Noir & Rouge"), the branded "First Spray" preloader, lightweight motion,
native WooCommerce integration and full Customizer control. All product data comes from WooCommerce.

== Installation ==

1. Appearance -> Themes -> Add New Theme -> Upload Theme.
2. Choose scentral-attraction-theme.zip -> Install Now -> Activate.
3. Appearance -> Customize -> Scentral Theme.
